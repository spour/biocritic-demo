# biocritic demo

A small limma-voom RNA-seq analysis (mouse mammary gland, GEO GSE63310), adapted from the Bioconductor workflow
RNAseq123 (Law et al. 2016, F1000Research 5:1408; CC BY 4.0). Run with `Rscript analysis.R`.

Used to test the biocritic review bot: write `/biocritic review` in a comment on a commit, an issue or a pull request.
